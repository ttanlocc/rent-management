  <name>Task 1: Create payment API routes</name>
  <files>app/api/payments/route.ts, app/api/payments/[id]/route.ts</files>
  <action>
Create `app/api/payments/route.ts` following the exact pattern from `app/api/tenants/route.ts`:

**GET handler** (list payments with filtering):
- Auth check (supabase.auth.getUser, return errors.unauthorized if not authenticated)
- Parse and validate query params using `paymentQuerySchema`: tenant_id, payment_status, start_date, end_date, overdue_only, page, limit
- Build Supabase query: `supabase.from('payments').select('*, tenant:tenants(id, full_name, room:rooms(id, name))', { count: 'exact' })`
- Apply filters:
  - If `tenant_id`: `.eq('tenant_id', tenant_id)`
  - If `payment_status`: `.eq('payment_status', payment_status)`
  - If `start_date`: `.gte('payment_date', start_date)`
  - If `end_date`: `.lte('payment_date', end_date)`
  - If `overdue_only === 'true'`: `.neq('payment_status', 'paid_in_full').lt('payment_date', new Date().toISOString())`
- Pagination: `.range(from, to).order('payment_date', { ascending: false })`
- Return `createSuccessResponse({ payments, pagination: { page, limit, total, totalPages } })`
- Error handling: ZodError -> handleZodError, Supabase error -> handleSupabaseError, other -> errors.internal()

**POST handler** (create payment with optional receipt):
- Auth check
- Parse multipart form data: `const formData = await request.formData()`
- Extract `data` field (JSON string) and `receipt` field (File or null)
- Parse and validate body with `createPaymentSchema`
- Verify tenant ownership: query tenant -> room -> property -> check user_id matches auth.uid(). Return errors.forbidden if not owner.
- If receipt file exists and has size > 0:
  - Generate a temporary UUID for file naming: `crypto.randomUUID()`
  - Upload receipt using `uploadReceipt(receiptFile, tempId)` from `@/lib/utils/storage`
  - On upload error, return errors.internal('Khong the tai len bien lai')
- Insert payment record with all validated fields + receipt_url
- If insert fails AND receipt was uploaded, cleanup: `await deleteReceipt(receiptUrl).catch(console.error)`
- If insert fails, return handleSupabaseError
- Return `createSuccessResponse(payment, 201)`

Create `app/api/payments/[id]/route.ts` following `app/api/tenants/[id]/route.ts`:

**Interface:** `RouteParams { params: Promise<{ id: string }> }`

**GET handler** (payment detail):
- Auth check
- Query payment with tenant relation: `.select('*, tenant:tenants(id, full_name, room:rooms(id, name, property:properties(id, name, user_id)))').eq('id', id).single()`
- Check ownership via tenant -> room -> property -> user_id
- Return payment or errors.notFound/errors.forbidden

**PUT handler** (update payment):
- Auth check
- Parse body and validate with `updatePaymentSchema`
- Fetch existing payment with tenant ownership chain
- Verify ownership
- Update payment: `.update({ ...validatedData, updated_at: new Date().toISOString() }).eq('id', id).select().single()`
- Return updated payment

**DELETE handler** (delete payment with receipt cleanup):
- Auth check
- Fetch existing payment with tenant ownership + receipt_url
- Verify ownership
- If payment has receipt_url, attempt to delete from storage: `await deleteReceipt(payment.receipt_url).catch(console.error)` (don't fail the delete if storage cleanup fails)
- Delete payment record: `.delete().eq('id', id)`
- Return `createSuccessResponse({ deleted: true })`

IMPORTANT: Import `deleteReceipt` from `@/lib/utils/storage` in the [id] route for cleanup. The storage utility uses the browser client, but for server-side delete we need to use the server client. Therefore, create an overloaded version or handle server-side deletion directly in the API route using `createServer()` Supabase client to call `.storage.from('payment-receipts').remove([path])`. Do NOT import the browser-client storage utility in a server-side API route. Instead, inline the storage delete logic using the server supabase client.

   ```typescript
   export const paymentKeys = {
     all: ['payments'] as const,
     lists: () => [...paymentKeys.all, 'list'] as const,
     list: (params: QueryParams) => [...paymentKeys.lists(), params] as const,
     details: () => [...paymentKeys.all, 'detail'] as const,
     detail: (id: string) => [...paymentKeys.details(), id] as const,
   }
   ```

6. **API functions:**
   - `fetchPayments(params)`: GET /api/payments with query string
   - `fetchPayment(id)`: GET /api/payments/{id}
   - `createPayment(data: FormData)`: POST /api/payments with FormData body (NOT JSON, since we need multipart for file upload). The FormData should contain a 'data' field with JSON string and optional 'receipt' field with File.
   - `updatePayment({ id, data })`: PUT /api/payments/{id} with JSON body
   - `deletePayment(id)`: DELETE /api/payments/{id}

   IMPORTANT: createPayment must send FormData (not JSON) because the API route expects multipart form data for receipt upload. The hook's mutationFn receives FormData directly (the component will construct it).

7. **Hooks:**
   - `usePayments(params)`: useQuery with paymentKeys.list(params)
   - `usePayment(id)`: useQuery with paymentKeys.detail(id), enabled: !!id
   - `useCreatePayment()`: useMutation with cache invalidation on paymentKeys.lists(), toast.success on success, toast.error on error
   - `useUpdatePayment()`: useMutation with invalidation on lists + detail, toast messages
   - `useDeletePayment()`: useMutation with invalidation on lists, toast messages

   Toast messages in Vietnamese:
   - Create success: 'Them thanh toan thanh cong!' (with proper diacritics)
   - Update success: 'Cap nhat thanh toan thanh cong!'
   - Delete success: 'Xoa thanh toan thanh cong!'
   - Error: use error.message from API response

8. **Helper function for building FormData** (exported for use by components):
   ```typescript
   export function buildPaymentFormData(
     data: Omit<PaymentFormInput, 'receipt_file'>,
     receiptFile?: File | null
   ): FormData {
     const formData = new FormData()
     formData.append('data', JSON.stringify({
       ...data,
       payment_date: data.payment_date instanceof Date
         ? data.payment_date.toISOString()
         : data.payment_date,
     }))
     if (receiptFile) {
       formData.append('receipt', receiptFile)
     }
     return formData
   }
   ```
