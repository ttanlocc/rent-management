Create the SQL migration file `supabase/migrations/20260215000001_create_payments.sql` with:

1. **Payments table:**
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `tenant_id UUID REFERENCES tenants(id) ON DELETE CASCADE NOT NULL`
   - `payment_date TIMESTAMPTZ NOT NULL`
   - `amount DECIMAL(15,2) NOT NULL CHECK (amount > 0)`
   - `payment_method VARCHAR(20) NOT NULL CHECK (payment_method IN ('cash', 'bank_transfer', 'check'))`
   - `payment_status VARCHAR(20) NOT NULL CHECK (payment_status IN ('paid_in_full', 'partial_payment', 'late_fee_applied'))`
   - `receipt_url TEXT` (nullable, stores Supabase Storage public URL)
   - `transaction_reference VARCHAR(255)` (nullable)
   - `notes TEXT` (nullable)
   - `created_at TIMESTAMPTZ DEFAULT NOW()`
   - `updated_at TIMESTAMPTZ DEFAULT NOW()`

2. **RLS policy** (follow existing pattern from tenants):
   ```sql
   ALTER TABLE payments ENABLE ROW LEVEL SECURITY;
   CREATE POLICY "Users can manage own payments" ON payments
     FOR ALL USING (
       tenant_id IN (
         SELECT t.id FROM tenants t
         JOIN rooms r ON t.room_id = r.id
         JOIN properties p ON r.property_id = p.id
         WHERE p.user_id = auth.uid()
       )
     );
   ```

3. **Indexes:**
   - `idx_payments_tenant_id ON payments(tenant_id)`
   - `idx_payments_payment_date ON payments(payment_date DESC)`
   - `idx_payments_status ON payments(payment_status)`
   - `idx_payments_overdue ON payments(payment_status, payment_date) WHERE payment_status != 'paid_in_full'` (partial index for overdue queries)

4. **Updated_at trigger** (reuse existing pattern if `update_updated_at_column()` function exists, otherwise create it):
   ```sql
   CREATE OR REPLACE FUNCTION update_updated_at_column()
   RETURNS TRIGGER AS $$
   BEGIN NEW.updated_at = NOW(); RETURN NEW; END;
   $$ LANGUAGE plpgsql;

   CREATE TRIGGER update_payments_updated_at BEFORE UPDATE ON payments
     FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
   ```

5. **Storage bucket for receipts:**
   ```sql
   INSERT INTO storage.buckets (id, name, public)
   VALUES ('payment-receipts', 'payment-receipts', true);
   ```

6. **Storage RLS policies:**
   - INSERT for authenticated users (bucket_id = 'payment-receipts', folder = 'receipts')
   - SELECT for authenticated users
   - DELETE for authenticated users

Create `lib/utils/storage.ts`:
